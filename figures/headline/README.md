# Legacy three-seed figure

The tracked figure in this directory is a legacy exploratory comparison of the repository's CNN placeholder and a generic spectral FNO built with `neuraloperator`. Its original legend uses the label “LiteFNO,” but the spectral arm is not a complete, paper-faithful implementation and omits the transduction stage. The figure must not be interpreted as evidence for or against the published LiteFNO architecture. See the root [README](../../README.md) and [reproducibility findings](../../docs/reproducibility_findings.md).
