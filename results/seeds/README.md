# Legacy three-seed outputs

These tracked tables are exploratory results from a comparison between the repository's CNN placeholder and a generic spectral FNO constructed with `neuraloperator`. The model labels have been clarified, but the numerical results are unchanged. This generic FNO variant omits the paper's transduction stage and has not been validated as a complete LiteFNO reproduction. Do not use these data to claim that the published LiteFNO performs better or worse. See the root [README](../../README.md) and [reproducibility findings](../../docs/reproducibility_findings.md).
